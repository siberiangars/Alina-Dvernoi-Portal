# Бот «Алина» — автоответчик на Авито для «Дверного портала»

Бот автоматически отвечает на сообщения покупателей на Авито от имени менеджера Алины. Ведёт диалог, собирает контактные данные (телефон, адрес) и отправляет готовую заявку в Telegram-чат менеджеров.

## Что делает бот

- Каждые N секунд опрашивает Авито на наличие непрочитанных чатов
- Отвечает клиентам с помощью Claude AI в образе живого менеджера
- Последовательно собирает: тип двери, детали, фото, размеры, телефон, адрес
- Когда телефон и адрес собраны — отправляет заявку в Telegram
- Логирует все входящие/исходящие сообщения и ошибки

## Требования

- Node.js 18+
- npm

## Установка

```bash
git clone <repo-url>
cd <repo-dir>
npm install
```

## Настройка

Скопируйте `.env.example` в `.env` и заполните переменные:

```bash
cp .env.example .env
```

| Переменная | Описание |
|---|---|
| `AVITO_CLIENT_ID` | ID приложения Авито API |
| `AVITO_CLIENT_SECRET` | Секрет приложения Авито API |
| `AVITO_USER_ID` | Числовой ID вашего аккаунта Авито |
| `ANTHROPIC_API_KEY` | Ключ API Anthropic Claude |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID чата/группы для заявок |
| `POLL_INTERVAL_MS` | Интервал опроса в мс (по умолчанию 15000) |

## Как получить Avito API ключи

1. Зайдите на https://developers.avito.ru
2. Создайте приложение в разделе «Мессенджер»
3. Скопируйте `client_id` и `client_secret`
4. `AVITO_USER_ID` — числовой ID вашего профиля (виден в URL профиля на Авито)

## Как получить Telegram Bot Token

1. Напишите @BotFather в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен в `TELEGRAM_BOT_TOKEN`

## Как узнать TELEGRAM_CHAT_ID

**Способ 1 — @userinfobot:**
Напишите боту @userinfobot — он ответит вашим ID. Для группы добавьте бота в группу и напишите `/start`.

**Способ 2 — getUpdates:**
Отправьте запрос в браузере (подставьте свой токен):
```
https://api.telegram.org/bot<TOKEN>/getUpdates
```
В ответе найдите `"chat": {"id": ...}`.

## Просмотр логов

Логи пишутся в `logs/bot.log` (JSON, уровень debug и выше).

```bash
# Следить в реальном времени (Linux/Mac)
tail -f logs/bot.log

# Только ошибки
grep '"level":"error"' logs/bot.log
```

В консоли выводится уровень info и выше в читаемом формате.
